# Personal Photography Portfolio

A responsive visual diary and photography portfolio built to showcase personal captures, ranging from landscapes to street photography. 

## Features
* **Responsive Photo Gallery:** Utilizes CSS Grid to ensure images are perfectly framed and adapt cleanly to mobile, tablet, and desktop screens.
* **Semantic HTML Structure:** Includes a structured biography, categorized photography styles, and a curated favorite photos section.
* **Interactive Navigation:** A responsive navigation bar utilizing Flexbox for easy access to different portfolio sections.
* **Contact Form:** A styled HTML5 contact form with active focus states and basic validation for user inquiries.

## Technologies Used
* HTML5
* CSS3 (Flexbox & CSS Grid)
* Git & GitHub (Version Control & Deployment)

## Getting Started

To view this project locally on your machine:

1. Clone this repository to your local machine using your terminal:
   `git clone https://github.com/Juniorsznnn/Photography-Website.git`
2. Navigate into the project directory:
   `cd Photography-Website`
3. Open the `index.html` file in your preferred web browser, or use a tool like the VS Code Live Server extension.
